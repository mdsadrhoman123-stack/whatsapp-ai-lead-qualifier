# Security policy

## Reporting something that should not be public

If anything in this repository looks like it should not be here — a credential,
an internal hostname, anything identifying a real business, or a file that gives
away the build — report it and it comes down first and gets discussed second.

**khandokarsayad@gmail.com** · **mdsadrhoman123@gmail.com**

Please do not open a public issue for this. Email is faster and does not leave
the thing on display while it is being fixed.

## What is deliberately not in this repository

No credentials, tokens, webhook secrets or API keys have ever been committed
here, and no workflow export is published — see [`NOTICE.md`](NOTICE.md) and
[`workflows/README.md`](workflows/README.md) for what is withheld and why.

This repository is documentation. It is not a runnable product, it holds no
customer data, and it is not pointed at anyone's live accounts.

## Scope

This policy covers the contents of this repository only. The system it describes
runs on my own infrastructure.
